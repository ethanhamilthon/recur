# Recur documentation

Run recur docs TOPIC with one of these topics:
- runtime: shell, timeouts, background jobs, state, prefix, and environment.
- images: recur view and queued image delivery.
- clipboard: image paste, textual attachment labels, shortcuts, and retention.
- sessions: configuration, saved histories, session switching, and restoration.
- steering: instructions queued while the agent works, acceptance, and recall.
- interface: commands, keyboard shortcuts, and rendering limits.
- models: provider setup, model/effort selection, and session metadata.
- hooks: hooks.toml, events, variables and delivery rules.
- headless: --prompt and JSONL transports, recur notify, and session ownership.

These topics describe implemented behavior, not the planned TODO backlog.
