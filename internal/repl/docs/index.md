# Recur documentation

Run recur docs TOPIC with one of these topics:
- config: unified recur.toml, precedence, options, status bar, and migration.
- runtime: stateless system Bash, timeouts, output limits, and background work.
- images: recur view and queued image delivery.
- clipboard: image paste, textual attachment labels, shortcuts, and retention.
- sessions: configuration hierarchy, saved histories, session switching, and restoration.
- steering: instructions queued while the agent works, acceptance, and recall.
- interface: commands, file path completion, padded status bar, and rendering limits.
- models: provider setup, api_key_env secrets, model/effort selection, and metadata.
- hooks: named hooks, send_output next-turn delivery, events, loop prevention, and variables.
- headless: --prompt and JSONL transports, hook isolation, recur notify, and session ownership.

These topics describe implemented behavior, not the planned TODO backlog.
